# Charis docs

Governing documents for the Charis translation. Read in order:

1. [PREMISES.md](PREMISES.md) — axioms. Lexical equivalence, canonical consistency, precision over familiarity, transliteration, machine-first structure.
2. [INVARIANTS.md](INVARIANTS.md) — machine-checkable rules every commit must hold.
3. [PROCESSES.md](PROCESSES.md) — repeatable workflows (word normalization loop, sense splits, collision resolution, xref audits, releases).
4. [TOOLING.md](TOOLING.md) — scripts + AI skills to build; determinism boundary between them.

Precedence: premises > invariants > processes > tooling. Conflicts resolve upward; amendments happen here, in version control, with rationale.
